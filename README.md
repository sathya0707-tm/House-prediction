
# House Price Prediction Using Linear Regression

## About the Project
This project uses Machine Learning to predict house prices using a dataset obtained from Kaggle.

A Linear Regression model is trained using house features such as living area, bedrooms, bathrooms, grade, condition, and location.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Linear Regression

## Features
- Data exploration and preprocessing
- Exploratory Data Analysis (EDA)
- Model training using Linear Regression
- Model evaluation using MAE, MSE, and R² score
- Actual vs. predicted price visualization
- House price prediction based on user input

## Dataset
The project uses `data.csv`. Check the dataset's license and usage conditions before sharing it publicly.

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the Python script:

   `python house_price_prediction.py`

4. Enter the requested house details to get a predicted price.

## Model Evaluation
The model is evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
